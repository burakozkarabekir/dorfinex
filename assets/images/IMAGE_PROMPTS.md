# - Logo/ikon (A1, A2, J1): Figma, DALL-E veya Midjourney

# - Thumbnails/OG (F serisi, J1): DALL-E 3 veya Ideogram
#
# Boyut Onerileri:
# - Hero goerselleri: 1920x800 (21:9 wide) veya 1920x1080 (16:9)
# - Service/card goerselleri: 800x600 (4:3)
# - Blog thumbnails: 1200x630 (OG) + 600x400 (card)
# - OG default: 1200x630
# - Mobile hero: 1080x1350 (4:5)

# - Her gorsel icin onerilen dosya adi prompt basliginda belirtilmistir
